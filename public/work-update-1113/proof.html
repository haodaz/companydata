作品存档与核验：做过的真活能带走、能被核对

候选人 · 看作品的人2 分钟读完

交卷出报告后，候选人可以把整份作品存成 PDF，放进简历和作品集。PDF 上有核验码、二维码和交付原文的数字指纹，别人扫码就能看到平台存的原件，改过的作品一对就知道。

1报告页：领成绩单，或保存整份作品

成绩单是一页分数和要点；「保存我的作品」是整份：任务书、交付原文、附件。

1成绩单：链接可发给下一家公司，也能存 PDF
2保存整份作品：任务书 + 交付原文 + 附件，带核验码
  • 1成绩单：链接可发给下一家公司，也能存 PDF
  • 2保存整份作品：任务书 + 交付原文 + 附件，带核验码

2作品存档：存成 PDF 带走

点「存成 PDF / 打印」，选「存储为 PDF」。核验链接可以单独复制发给别人。附件里平台读出的文字默认折叠，以原文件为准。

1存成 PDF
2复制核验链接
3任务书、交付原文、附件都在一页
  • 1存成 PDF
  • 2复制核验链接
  • 3任务书、交付原文、附件都在一页

3PDF 最下面：核验码、二维码、数字指纹

数字指纹由交付原文算出来，原文改一个字，指纹就完全不同。

1扫码看平台存的原件
2核验码
3交付原文的数字指纹：改一个字就对不上
  • 1扫码看平台存的原件
  • 2核验码
  • 3交付原文的数字指纹：改一个字就对不上

4扫码进核验页：看到的是平台存的原件

核验页公开、只读，显示作答人姓名（不显示手机和邮箱）、交卷时间、分数、任务书、交付原文和附件原件。

1这一页是平台存的原件，作答人改不了
  • 1这一页是平台存的原件，作答人改不了

5想核对手里那份：整段粘进来

把手里那份的交付原文整段原样粘进来，马上显示一致还是不一致；不一致时也可以直接对照上面的原文看哪里不同。

1把手里那份的交付原文粘进来
2一致 / 不一致，马上知道
  • 1把手里那份的交付原文粘进来
  • 2一致 / 不一致，马上知道
