# 高瓴演示脚本（2026-10-26）

只演示结果，不讲原理。全程 15 分钟上下，三段。

## 0 开场（1 分钟）

一句话：你们要找什么样的人，直接说，不用套职位名。我们当场出一道这个人此刻在高瓴该干的活，让候选人做，做完出报告。

准备好的底子（不用展示，被问到再说）：高瓴资本 + 高瓴创投两条实体已关联（张磊、易诺青、马翠芳共同高管）；七个投资机构深度专题（基金 / 策略 / 被投 / 合伙人 / 网络 / 风险 / 招聘）；10 月动态（观复芯、源归材料、庆为航空、NOTA 东京 IPO、旗舰基金募资）；社招 + 实习岗位 16 条（猎聘公司页）。

## 1 聊着出题（5–6 分钟，主菜）

页面：www.aidataoffice.com/work/new/chat（登录态提前准备好，新对话）

- 对方说，或者我们替他说：**「我要一个能看懂 AI 基础设施、来做早期投资的人。」**
- 助理会：搜到高瓴资本 → 看材料厚不厚 → 问要不要给候选人素材（说「这次不用」）→ 问有没有过往的题（说「没有」）→ 复述题意 → 出题（约 2 分钟）→ 跑基线（1 分钟）→ 三五句说这道题。
- 等出题的两分钟，讲右侧空间：业务问题、为什么是现在、依据（每条标来源）、交付物、推进步骤、材料包、评分标准。
- 出好后点「看 →」，右侧就是这道题的空间；复制参与链接。

**备份**：出题超过 3 分钟或报错，直接切到预出的题（见下表），说「这是昨天出的同一类题」。

## 2 候选人怎么做（3 分钟）

打开参与链接（手机或新窗口）：

- 三种做法并列：本页操作台 / 自己的网页工具 + 真活插件 / 桌面软件 + 录屏。
- 点进操作台：左材料包（含附件表格 / 图）、中间交付文档、右 AI 随便用（评的是怎么用）。
- 不现场做题。切到「做题情况」看一份已做完的报告：候选人交付物原文 → 评价体系逐条打分 → 和 AI 基线的差距。

## 3 收尾（2 分钟）

- 题出完就在题库里，哪里不对说一句就改（演示「按意见修订」输入框，不用真点）。
- 一句话收：这是企业数据底座 + 职业库 + 行业规范撑出来的，高瓴的每一条依据都能点回来源。

## 现场注意

- 演示前一小时不跑任何批量任务；线上库并发留给演示。
- 浏览器两个标签：聊着出题、参与链接；第三个标签开备份题的空间。
- 不说「样本」「训练」「飞轮」「基线怎么定」；被问评分谁评，说「评价体系在评，标准每条都能看」。
