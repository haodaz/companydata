1 · 咨询 / 商学院案例
276 道 · r2		 11 本 MBA 咨询俱乐部 casebook（2008–2025，Darden / Kellogg / Wharton / Stern / Yale / MIT / McGill / Ross）。每道：面试官脚本、分阶段才给的 exhibit 数据表、参考答案、评分提示。题型：盈利改善 82、投资判断 66、市场进入 63、增长战略 31、定价 8、市场估算 / 运营等。 interviewer-led：搭框架 → 看图表下判断 → 测算（正推 / 反推）→ 出主意 → 综合建议，4–8 步；每步的 reveal（当步给的数据）、expected（参考答案）、calc（算式，代码真算）；style_notes 记手法（数据按需逐步披露、结论回扣目标、测算要解读商业含义）。 战略 / 投资 / 咨询 / 产品 / 运营 / 市场类岗位，以及「直接说要找什么样的人」的需求（能看懂某行业来做投资、能做增长测算的人）。文档 / 对账台，分步推进；评分核对测算数（±5%）和判断理由。第二轮示例：武岳峰 · 具身智能三选一领投判断（基线 88）。
2 · 工程 take-home 作业
4 份 · r2（待扩）		 公司自己公开在 GitHub 的作业题：SpotOn、Analytics & Automation、NYC Jobs 三份数据工程，一份软件工程。带数据源 / 接口、时限（2–5 小时）、评审口径（可运行、README、取舍、边界情况）。下一批：datadriven 等整理的 47 份带 rubric 的真题、数据分析 / 产品 / 设计类作业。 take-home：取数 → 建模 / 清洗 → 产出 → 文档 / 测试，3–6 步；每步 reveal 是输入（数据集、接口、约束），expected 是评审看什么；style_notes：限定时长、要可运行、README 说取舍、诚实标注未做的。 程序员 / 数据工程 / 数据分析 / 算法 / 后端等工程师岗位。代码台（浏览器里跑自测用例）或 表格 / 数据台；也适合「用自己的工具做 + 插件记过程」。第二轮示例：阿里 · 千问导购推荐下单归因评测模块（基线 84）。
3 · 职业技能等级认定实操考核
42 份 · 26 工种 · r2		 广东人社厅技工院校技能等级认定的公开技术文件：技能考核试卷 / 样题、评分记录表、考场与考生准备通知单，按三级 / 四级 / 通用分档。工种覆盖数控车铣、机床装调、模具、钳工、电工、工业机器人、制冷、物联网、网络安全、AI 训练师、无人机、汽车涂装、砌筑、钢筋、化学检验、废水处理、消防、物流、HR、营销、直播销售、中西烹调、餐厅服务。其余 60 多个工种可续收。 practical：考核项目 / 工序各一步（排故、装调、编程、检测、文明生产），reveal 是条件（图纸、材料、设备、时间），expected 是评分标准原文（配分、扣分档位、否定项），calc 为空；style_notes：配分扣完为止、超差不得分、否定项一票否决、自检与实测对比。 制造 / 电气 / 机械 / 服务类蓝领与技师岗位：电工、PLC、数控、钳工、维修、机器人运维、烹调等。设计台（参数表 + 接线 / 工艺草图 + 说明）当机考台雏形，也可配录屏做真实操作；评分直接沿用人社评分表口径。第二轮示例：宁德时代 · 德布勒森试产线电气排故与调试（基线 79）。下一步：自主机考台（电路 / PLC / CAD / 数控可自动校核）。
