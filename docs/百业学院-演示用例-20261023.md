# 百业学院 · 两个演示用例（2026-10-23）

教务处：`/college/admin`（内部）。学员 = 模型；课程 = 百业工厂的空间；教材 = 空间里的技能卡 + 每章教案 + 示范轨迹；考题 = 真活台的真活。学院只多了三层薄账：学员、学籍（含学习笔记）、去向。两个用例的教材由院长 A 备，脚本在 `scripts/college-demo-*.mts`，id 在 `scripts/.college-demo.json`。

## 用例 1 · 投资机构 · 能看懂具身智能的行业分析师

- 需求方：武岳峰资本（企业库 892）。培养需求单原话：「我要一个能看懂具身智能的人来做投资……判断技术路线靠不靠谱（真泛化还是遥操作 demo）、离量产多远（BOM、关节模组从哪来）、团队行不行、第一个付钱的场景是什么，然后写一页纸给投委会。」
- 课程：百业空间「行业分析师（具身智能方向）」，粘贴 JD 流水线建，JD 正文就是教材大纲：
  1. 产业图谱五层：本体 / 大脑（VLA、世界模型）/ 小脑（RL、MPC、sim2real）/ 数据（遥操作、仿真、视频；数据飞轮成不成立）/ 核心零部件与供应链（关节模组、灵巧手、感知；国产化率与成本曲线）；落地场景优先级与付费证据。
  2. 跟踪方法：顶会与开源、公司融资与估值对标、产业数据、政策；每周一份 2 页周报。
  3. 项目判断框架（投委会四件事）：技术路线、离量产多远、团队、商业化与估值。
  4. 日常产出：BP 速读与一页纸备忘、尽调访谈提纲、投委会答辩准备、投后里程碑。
  5. 师傅的判断规则：看 demo 先问成功率 / 是否遥操作 / 任务分布；谈 BOM 问减速器与电机来源；宏大叙事按场景折现；估值对标不跨阶段不跨路线；一页纸结论先行、三理由、两风险、每条有出处。
- 真活：「我要一个能看懂具身智能的人来做投资」@ 武岳峰资本，文档台。给一家人形机器人公司的 BP 与公开资料，写一页纸投资备忘；材料里有一份有坑（demo 成功率口径 / 估值对标跨阶段）。AI 基线先做一遍。
- 学员：通义千问 Plus（国内模型）。定向学籍 → 入学考 → 逐章上课 → 毕业考 → 没过的章反思补考 → 做真活 → 毕业 → 派去武岳峰资本的需求单。

## 用例 2 · 生物实验室 · 能做数据处理与文献分析的研究员

- 需求方：科研版机构「演示·肿瘤免疫单细胞多组学实验室」（工作台 ws_orgs，kind=research）。机构档案（研究方向、在研项目、平台、团队、引进层次、考核）写在 context 里，课程贴着它建。
  - 研究方向：肿瘤微环境中耗竭 T 细胞（Tex）亚群的异质性与 PD-1 免疫治疗应答标志物。眼下卡在：多批次 / 多患者数据整合后耗竭亚群边界不稳定，差异基因在验证队列复现不出来。
  - 在研：国自然面上（scRNA-seq + TCR-seq 治疗前后克隆动态）、院级（Visium 空间转录组）、与附属医院胸外科的前瞻队列（有伦理批件）。
  - 平台：10x Chromium、NovaSeq、FACSAria、Visium、HPC（Slurm；Seurat / Scanpy / scVI / CellChat）、样本库与 LIMS、BSL-2。
- 研究员要会的（用户说「还有什么我不懂，需要你想」，我补齐的）：
  1. **数据处理**：QC（细胞数、线粒体比例、基因数分布）、去双细胞、批次整合（Harmony / scVI / CCA 怎么选）、聚类与注释、差异与轨迹、TCR 克隆分析；每一步的参数为什么这么选。
  2. **文献分析**：检索策略、批判性评价（样本量、对照、统计、数据可得性）、判断结论能否复现、journal club 讲解。
  3. **实验设计与统计**：对照、样本量与功效、多重检验、前瞻队列分组。
  4. **伦理与生物安全**：知情同意、伦理批件范围、BSL-2 操作。
  5. **组会汇报与可复现代码**：讲清楚、代码别人能跑（Git、流程文档）。
  6. **基金本子**：研究背景与科学问题一段。
- 课程：研究岗空间「单细胞多组学方向博士后研究员」，研究岗提示词（贴着在研项目与平台写，像新人进组第一个月）。
- 真活：研究真活 · 数据分析，数据台。8 个新样本（4 应答 / 4 无应答，两个批次）的 QC 表与初步聚类：标异常样本、判断批次效应、选整合方案并说理由、给耗竭亚群注释与验证计划、写下一步统计方案；材料里有坑（某样本线粒体异常 / 两批测序深度差一倍）。
- 学员：Claude Sonnet 5.5。路径同上，毕业后派去实验室的需求单。

## 学习过程里「给 AI 什么」（五层，考试时一起装进去）

技能卡（老师傅规则）→ 教材要点（上课：教案 + 示范 → 要点进笔记）→ 错题本（反思：对照评分证据与示范，写错在哪、记住什么规则）→ 知识包（平方图谱）→ 真活经验。评分永远用老师傅原版技能卡，学员笔记改不了标准。补训 = 没过的章反思进错题本再考。

## 怎么复现

```
npx tsx scripts/college-demo-prep.mts            # 机构 + 两份需求单 + 两门课（claude-opus-5-5）
npx tsx scripts/lab-build-full-day.mts <两门课 id 前 8 位> --model claude-opus-5-5   # 扩成完整一天
npx tsx scripts/college-demo-work.mts            # 两道真活 + AI 基线
npx tsx scripts/college-demo-train.mts           # 开定向学籍，按路径培养到毕业，派去需求单
```
教务处里每一步也都能人工点。测试数据都留着不删。
