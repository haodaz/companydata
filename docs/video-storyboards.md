**正片**：十五个职业，每个一段，结构固定——
1. 亮相（4–5 s）：这个行业 + 人物（NOVA 立绘）+ 空间环境（空间主页 / 3D 房间，鼠标晃一下有景深）
2. 操作（20–25 s）：直接进操作台，不停留在对话 / 答题页；变化大的操作截几个不同环节（例如开腹：下刀 → 撑开 → 镊子夹起 → 牵开器；拉花：打奶 → 融合 → 成图 → 收尾）
3. 旁白：形容这个职业的人正在做什么（「潜导把客人护在一臂之内，气压表到 70 bar 就回转」），不讲产品

顺序建议（视觉节奏错开：手艺 / 办公桌 / 照护 / 现场交替）：
外科 → 拉花 → 数据分析 → 月嫂 → 古籍修复 → 急诊分诊 → 中餐厨师 → 审计 → 潜导（珊瑚礁）→ 电气维修 → 客服 → 园艺 → 直播中控 → 幼儿园老师 →（外科缝合 / 其他）

**片尾（12–15 s）**：一幕幕画面缩小、汇聚成「百业」缓缓滚动的列表（体验馆那一排），静止两秒，出字幕：「来百业，感受千行百业的门道。」

## 片二 · 平方智能的 AI（面向合作方 / 投资人）

讲的是 AI 本身，不是体验者。顺序：**先看能做到什么 → 老师傅怎么把本事交给它 → 最后才讲为什么能**。

**第一幕 · 能做到什么程度（吸引眼球，40–60 s）**
- 输入一个职业名 / 一份 JD → 几分钟后：一位数字职人（NOVA）+ 一整天的章节 + 操作台 + 3D 房间（穿插最好看的几个空间：手术室、咖啡吧台、珊瑚礁、婴儿房）
- 向下：**教学**（我教你，NOVA 走一遍）、**考核**（考考你，评分、证书）
- 平行：**解决行业问题**（问问我、我被用在哪：被调用 N 次、N 地）
- 向上：**吸收专业知识**（你教我：老师傅校正）

**第二幕 · 老师傅（30–40 s）**
- 老师傅进空间**做操作**（不是观摩）→ 做完**深度访谈**：为什么这一步这么做、什么时候会出错、新手最常犯什么
- 访谈内容回写：规则 / 目标 / 示范轨迹更新 → 数字职人换了一个版本（演化）
- 旁白：它不是从教科书学的，是从一个个真人手里学的

**第三幕 · 为什么能（30–40 s，参考 vsbp：dataspace.html / upscale.html / ai-native.html）**
- 底座：数据飞轮（需求信号 → 热度与缺口 → 自动排产 → 加工入库 → 更优服务）、知识编织空间（SQUARECORE = KNOWLEDGE SQUARE + SQUAREAI + FLORA；物连物 · 物连人 · 人连人）、三间数据工厂、44 类实体行业级图谱
- **给人升维**：六层信源托举——检索 / 验真 / 测评 / 长期 / **操作** / **谈话** → 九维升维体。数字职人空间正是「操作 · 看你怎么干」和「谈话 · 听你怎么说」这两层的来源
- **建空间 = 给一个 AI 数字人升维**（不是做一个 skill）：技能只是一个点；加上**所处的环境**（空间 / 3D 房间）、**和人的关系**（角色表：带教、同事、客户）、**和物的关系**（「物」包括企业、空间、道具等各种：岗位所属的公司和行业、手术室 / 礁区这些空间本身、器械 / 奶缸这些道具、无影灯 / 麻醉机 / 咖啡机 / 电控柜这些仪器设备）、**时间的迁移与发展**（一天的章节、版本演化）——物连物 · 物连人 · 人连人 + 时间轴，数字职人落进和真人同一套九维空间，才能「升维配升维」
- 收：数字职人向下教与考、平行解题、向上学习，持续演化；人在里面做过的每一件事，都成为他升维的证据

**封面**：「平方智能：AI 职人与虚拟职业空间」，副题「一份 JD，长出一个会教、会考、会干活、会学习的 AI」。**结尾字幕**：「平方智能 · 构建人与 AI 的升维空间」。（用户 2026-10-11 定）
