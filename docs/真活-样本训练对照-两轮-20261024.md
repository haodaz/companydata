## 三、请老王看什么

1. **同一个需求三代**：武岳峰「能看懂具身智能的人来做投资」——训练前的整理题 → 第一轮 5 步跟投测算 → 第二轮 3 步三选一领投判断。哪个像一道能拿去用的题。

3. **骨架对不对**：后台「样本库」tab 点几份，看拆出的步骤 / 参考答案 / 手法行家认不认。

## 四、训练思路与参考集

- 样本不是题库，是**骨架库**：一道题拆成「几步、每步给什么、参考答案、要算的数、评分手法」；同一职业几十道拆完，共性就是这个职业的考核 mindset。出题时先按岗位 / 题型挑最像的骨架，再换成这家企业的真实处境。
- 参考集三类：咨询 / 商学院案例（思辨 + 测算）、工程 take-home（可运行交付 + rubric）、人社实操考核（工序 + 评分表 + 否定项）。
- 入库即挂实体：职业（occupation_id）、类型、标签、轮次；实操类对应行业标准和老师傅规则。324 份里 101 份挂上职业；电工、钳工、模具工等 19 个蓝领工种职业库里还没有，补上即可全挂。
- 全部由工具跑：切题 → 解析 → 入库 → 回填；千问跑批，解析零失败（324 / 324），测算算式代码核算。

## 五、下一步要资源的两件事

1. **样本工程常态化**：每周一批（更多 casebook、各省人社实操文件、面经统计出职业骨架），工具 + 单一模型跑，人只抽查。
