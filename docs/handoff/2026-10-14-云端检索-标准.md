# 交接备忘录 · 第二项：补「行业标准与操作规程库」（2026-10-14）

> 给云端 Claude 会话：先 `git pull`。流程、作答规则、不要做的事和《2026-10-14-云端检索.md》完全一样（同一个脚本 `scripts/agent-research.mts`），这里只说新增的 `standards` 这一步。

## 要做什么

标准库（`industry_standards`）现在 331 条，只挂到 70 个职业上；**还有 520 个职业一条标准都没有**。`standards` 这一步按职业出题：找真正约束这个职业日常操作的——

- 国标 / 行标 / 地标 / 团标：安全规程、技术与工艺规范（带数值窗口）、检验验收、服务规范
- 法规与主管部门规章（安全生产、职业卫生、行业准入）
- **仪器设备的操作手册 / 使用说明书**：题目里列了这个职业的常用设备，找厂商官网 / 文档中心的官方手册（`doc_type: manual`，`kind: vendor`，写清型号）。仪器手册就收在标准库里，**不用改物品库**
- 国际参考：ISO / IEC / IEEE，**美国劳工部 OSHA（29 CFR 1910 通用行业 / 1926 建筑业）**、NIOSH、ANSI——只在确实管到这个职业的操作时列，国内标准优先。O*NET 只用来核对工具，不是标准，别列

每条要完整题录（标准号、名称、发布单位、现行 / 废止 / 被代替、发布 / 实施日期、官方链接）+ 最多 10 条操作要点。

## 怎么做

```bash
git pull
npx tsx scripts/agent-research.mts status
npx tsx scripts/agent-research.mts next standards --n 3 --ids 566-599     # 先第八批，再 --ids 11-77（百业），再其余
# 打开 agent-work/inbox/standards-<id>.json，按题目要求作答，答案写进 answers["Standards"]（JSON 对象）
npx tsx scripts/agent-research.mts save agent-work/inbox/standards-566.json
npx tsx scripts/agent-research.mts skip agent-work/inbox/standards-581.json "没查到管这个工种的现行标准"
```

同一个职业，**做过 `context`（场所工具）之后再做 `standards` 更好**——题目会带上它的设备清单，手册才找得准。和前面四步可以穿插：一个职业做完 fill → graph → context → tasks → standards 再换下一个。

## 作答规则（标准这一步特别要紧）

1. **标准号、年份照官方原样写，查不到就 null，绝不编号、编年份、编数值。** 标准号在全国标准信息公共服务平台（std.samr.gov.cn）、行业标准平台（hbba.sacinfo.org.cn）、团标平台（ttbz.org.cn）核对；OSHA 在 osha.gov 核对条文号。
2. **优先现行版本**；查到的是被代替的旧版，就写新版，`replaced_by` 写清楚。
3. **要点用自己的话转述**，每条一句、不超过 60 字、带上关键数值；**不抄原文**（版权）。全文只给官方链接。
4. 手册只要厂商官网 / 文档中心的，不要文库、网盘、论坛转载。
5. 宁缺毋滥：一个职业找到 3–8 条真管用的就够；确实找不到就 skip 并写原因（会记进库，不再重派）。
6. 写库是「只填空」：库里已有的同一条标准会被补全，不会覆盖人工审过的。
