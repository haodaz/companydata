## 一、要做什么

职业库（Supabase `occupations` 表，602 个职业）要补四个「维度」。每个维度一道或几道题，题目就是原来发给模型的提示词，原样照做：

| step | 补什么 | 还缺（10-14 晚） |
|---|---|---|
| `fill` | 空着的别名、简介、工作内容、职业要求、证书、代表人物、相关专业 + 分工作年限月薪 | 315 |
| `graph` | 发展图谱（技能树 / 成长阶梯 / 晋升转型 / 入行路径）+ 各国薪资 + 中国各省市薪资 | 520 |
| `context` | 工作场所 + 工具设备（工具 / 设备 / 耗材 / 软件 / 防护 / 单据 / 证照） | 520 |
| `tasks` | 典型任务 + 工位 / 操作台 | 526 |

**先做哪些**（用 `--ids` 指定）：
1. 第八批新职业、新工种：`--ids 566-599`（34 个，人社部 2026-09-09 发布，最新）
2. AI 百业里已有的职业：`--ids 11-77`（百业的「和我聊」直接用这些数据）
3. 其余按编号顺序

每个职业建议的顺序：`fill` → `graph` → `context` → `tasks`（后面的题会用到前面的结果，比如 tasks 要用 graph 的技能节点和 context 的场所 / 工具）。

## 二、怎么做（循环）

```bash
npm ci                                                        # 第一次
npx tsx scripts/agent-research.mts status                     # 看还剩多少
npx tsx scripts/agent-research.mts next graph --n 3 --ids 566-599   # 领 3 个职业的题 → agent-work/inbox/graph-<id>.json
# 打开题目文件：questions[] 里每道题有 task 和 prompt。按 prompt 联网查、按 prompt 要求的 JSON 结构作答，
# 把答案（JSON 对象，不是字符串）写进同一个文件的 answers[task]，一个职业的几道题都答完——
npx tsx scripts/agent-research.mts save agent-work/inbox/graph-566.json    # 交卷：解析 + 写库，文件挪到 done/
npx tsx scripts/agent-research.mts skip agent-work/inbox/graph-581.json "查不到原糖保管员的薪资和职级资料"   # 实在查不到
```

`save` 报「答案不合格」就按提示补全再交（比如图谱的 skills / ladder 不能是空的）。`save` 之前那个职业这一步已经被补过的，会直接跳过不重写。

## 三、作答规则（重要）

1. **绝对不编。** 每个数字、职级、证书、人名、标准号都要来自你这次实际查到的网页；查不到的字段按题目要求填 `null` 或省略。宁可少，不可错。
2. **给出处。** 题目要 `sources` / `source_url` 的都填你真正打开过的链接。不要写没打开过的网址。
3. **薪资**只用可查的数据源（国家统计局、各省人社 / 统计局、职友集、看准、BOSS / 智联城市报告、BLS、ONS 等），写清年份；同一个数各处差得离谱就不填。新职业（第八批）多半没有可靠薪资——**没有就空着**，不要用相近职业的数顶。
4. **大类 / 小类、薪资年限档、技能 id 等**只能用题目里列出的取值。
5. 中文作答，职位头衔和工具设备用中国行业里的真实叫法。
6. 每道题的检索不用太多，3–6 次搜索够用就交；节省额度，别在一个职业上耗太久。

## 四、不要做的

- 不要调用任何大模型 API，不要改 `.env`，不要提交 `agent-work/`（已在 .gitignore）。
- 不要改代码；如果脚本报错（不是「答案不合格」那种），停下来，把报错原文写进 `docs/handoff/2026-10-14-云端检索-问题.md` 提交到新分支，等本地处理。
- 不要直接改数据库里的其它表 / 其它职业的数据；只走 `save`。
- 不要往 main 推代码（推 main 会触发线上部署）。

## 六、环境（用户在云端环境设置里配好）

- 环境变量：`NEXT_PUBLIC_SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`（和 Vercel 上的同名变量同值）。这把钥匙能读写整个库，只放在环境设置里，不要写进任何文件。
- 网络：要能访问 Supabase（`*.supabase.co`）和 npm。
- 安装：`npm ci`。
- 第一条命令跑 `npx tsx scripts/agent-research.mts status`，能打出四行「还缺 N 个」就说明环境通了。
