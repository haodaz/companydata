# AI 百业：工厂 / 体验改造方案

先在海外这套（companydata + 海外 Supabase）做完验证，公司的 `eng/simulator` 再按提交挑过去。
/lab 的提交只碰 /lab 相关文件；迁移一律可重复执行（公司 CI 的 sync-db 会整份重跑）。

## 三个主页面

| 页面 | 给谁 | 内容 |
|---|---|---|
| 百业首页 `/lab` | 所有人 | 宣传首页 |
| 百业工厂 | 编辑 / 审核 | 空间列表（含草稿）、工作室 `/lab/studio/<id>`：编辑章节和步骤、单步重写、锁定、校验、发布 |
| 体验百业 | 学生、其他产品平台、投资人 | 体验馆（所有已发布空间）+ 单个资源页（只读已发布版本，一天时间轴，按章体验） |

两边部署页面一样，只是拦截不同：

- 海外（融资演示）：`LAB_PUBLIC=1`，整个 /lab 免登录；生成 / 删除 / 发邀请 / 蒸馏仍要登录。
- 公司：/lab 要登录（管理端）；外部平台的用户走统一认证进单个资源页。从外部平台嵌进来的只显示当前资源，不显示菜单和返回入口（按「怎么进来的」决定，不是按部署）。

## 数据模型

- 空间：`skill_tasks`（不动）；加 `bible`（空间设定：一天大纲、人物表、地点库、要前后一致的事实）。
- 章节：`lab_chapters`，一段故事线 = 一章（时段 slot、标题、类型 日常 / 突发 / 考核、sim、示范轨迹、评分标准、草稿 / 已发布、锁定）。
- 生成任务：`lab_jobs`（替代进程内存里的进度，多副本 / Pod 重启不丢）。
- 发布版本：`lab_releases`（第 4 步，整个空间某一刻的冻结快照 = 空间包 / 对外只读接口的来源）。

老空间：`sim` 原样变成第 1 章（迁移 015），`sim` 列保留；读的时候有章节读章节，没有就读 sim。
触发器兜底：新建空间自动建第 1 章；只有一章且没锁定时，`sim` 改了同步到第 1 章。

## 「一天」的规则（用户 2026-10-09 明确要求）

1. **按时间排**：章节按时段排序（`sortByDay`），时间轴上按时间顺序显示。
2. **内容配得上时段**：早上做晨会 / 交接 / 准备 / 巡检，中段做核心操作和处理事情，下午到傍晚才是收尾 / 复盘 / 交接班。**别一大早干一个全天复盘的事情。**
   生成一天大纲时按这个顺序排；校验时发现「复盘」排在早上、「交接班」排在中午这类，标红、不许直接发布。
3. **前后接得上**：后面的章节要能接住前面发生的事（上午的客诉，傍晚复盘时要提到），由空间设定里的「已发生的事」串起来。
4. 有的职业不是「一天」，可以是「一周」「一个项目周期」，时段写成「周一上午」之类，规则同样适用（按先后、内容配阶段）。

## 生成方式：先骨架，再一段一段生成（用户 2026-10-09）

1. **先出骨架**：职业底稿 + 一天时间轴（6–10 格：时段、标题、要交代的事），不出题、不出图。
2. **管理员按格生成**：点哪格生成哪章，可附一句要求；不满意单独重来，不影响别的章节。
3. **素材和人物整天复用**：人物表（NPC 立绘）和地点库（场景图）放在空间设定 `bible` 里，一个空间画一次；
   生成章节时只能从已有的人物 / 地点里挑，确实要新的才加进设定、补画一张（之后别的章也能用）。
   同一天里早上的带教师傅下午还是同一张脸，早上巡检的车间下午出故障还是那个车间；图也不用每章重画，省钱。

## 人物与场景两级复用（用户 2026-10-09：「面对的客户、同事之类，做得越多，可复用的就越多」）

- **跨空间演员库**（在现有 `lab_art_assets` 上扩展：按职业领域 + 角色类型存）：顾客 / 客户 / 同事 / 主管 / 实习生 / 病人家属这类通用角色，
  以及车间 / 门店 / 会议室这类通用场景。新空间、新章节先从库里挑，挑不到才画新的，画完回到库里。
  同一个「挑剔的顾客」可以出现在咖啡师、奶茶店、零售店好几个空间里。数字职人本人的立绘不复用（以前同领域撞脸）。
- **本空间阵容**（`bible.cast` / `bible.places`）：从库里挑定或新画的人和地点记进空间设定，这一天的几章都用同一批，保证同一张脸、同一个地方。
- 库越大，新空间要画的越少，越做越省钱、越快。

## 分步

1. 章节底座：章节表 / 任务表、老空间迁成第 1 章、空间页能选章节（迁移 015）——进行中
2. 百业工厂：工作室手工编辑 + 实时预览（复用 SimRunner / BenchRunner）+ 校验 + 草稿 / 发布；导航改成「首页 / 百业工厂 / 体验百业」
3. 体验百业：体验馆 + 单个资源页（只读已发布）、分享链接；教教我 / 重建工位挪到工厂
4. 分层生成：职业底稿 → 一天大纲（按上面的规则）→ 按格生成章节 → 单步重写 / 锁定；连贯性检查走便宜模型
5. 发布版本、空间包 v2（manifest 带版本号 + chapters 数组）、只读接口
