# AI 成本记账口径（智能企业数据工厂 · 2026-10-18）

给院校项目参考。目标只有一个：**账要算全、按市价算**——免费额度、个人充值、Claude Code 会话里干的活，都按对应模型的官方 API 价折成钱，不因为「没花钱」就不记。

## 一、怎么记（三层）

1. **调用方记账**：每个功能调用大模型后 `logTokenUsage({ tool_name, task_name, model_id, usageMetadata, search_calls, units })`，记到 `token_usage_logs`。
2. **兜底记账**：`llm-client` 对每一次成功调用先自动记一笔「未归属」，记录编号留在返回值上；调用方随后正式记账时改这同一条，不重复。谁忘了记，账上至少有「未归属」这笔，总数不漏。
3. **系统外补记**：不经过 API 的花费（Claude Code 出题模式、Nebius 黑客松额度、Veo 视频等）用脚本直接记金额或按件数：`lab-log-cost.mts --tool external --usd 120` / `--units 8`。按条数记（一条职业画像一行），调用次数才对得上。

每笔记录带：模型、功能（tool_name）、环节（task_name）、对象（企业 / 职业名）、token in/out、联网搜索次数、按件数量、成本（统一折美元）、归属（空间 / 章节 / 任务 / 谁触发 / 环节 create·use·review·media）。

## 二、价目表

`model_pricing` 表（后台可编辑）优先；没登记的用代码里的默认价。token 按百万计、联网搜索按千次计、出图按张、视频按秒。千问按人民币价、其余按美元价，汇率统一折算。Claude Code 会话里做的活按 **Fable API 价**（$10 / $50 每百万 in / out）反推 token 记入。

## 四、为什么这么分

- **职业画像是低频高价**（一条 ≈ $0.8，630 条 ≈ $504），**获取岗位是高频低价**（3 万多次 ≈ ¥337）。不分开，看总数的人会以为挖岗位很贵。
- 「未归属」单列是为了暴露漏记：它不该一直很大。
- 「系统外补记」单列是为了让垫付的钱（黑客松额度、个人订阅）在总账里可见，预算别按低估的数字定。
