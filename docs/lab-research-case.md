## 两个台面

**glovebox**（`src/lib/lab-glovebox-spec.ts` + `surfaces/Glovebox.tsx`）：写实底图 + 极简叠层，东西都在图上点。
过渡舱抽洗三次再开内门 → 开瓶称 80 mg Li6PS5Cl → 盖瓶 → 倒进模具 → 按住压片机到 350–400 MPa 保压 3 秒 → 卸压。
压完片 8 秒后右手手套有针孔，水值往上爬：盖瓶、点手套找到针孔、盖手套口盖、开循环净化，等水值回到 0.1 ppm 以下再贴锂、调堆叠压力 3–8 MPa、封装送出。
红线：没抽洗够开内门、粉瓶开着遇水放 H2S、超压压裂、水值没降就贴锂、堆叠压力过大锂蠕变短路。烟雾弹：开内门时氧值小跳。多的粉倒回原瓶是提醒（会污染整瓶）。

**eis**（`src/lib/lab-eis-spec.ts` + `surfaces/Eis.tsx`）：浅色整屏分析软件。
三只裸锂对称电池（静置不通电 / 0.1 / 0.5 mA/cm²）各五个时间点。小幅值测量 → 剔除高频感抗点 → R_b + (R_int‖CPE) + W 拟合 → 看 R_int 对 √t →
0.5 那只 100 h 后偏离直线 → 加压复测，回来大半 → 结论「两种机制都有：静置也在长的是化学分解，大电流下多出来、加压能回来的是接触失效」。
这正是研究真活要设计实验去证实的判断，所以台面和真活是一前一后。

## 怎么做出来的（照着做下一个）

1. 科研版工作台里建机构、边聊边配 know-how（研究问题 / 在研项目 / 平台 / 引进层次 / 考核）。
2. `npx tsx scripts/lab-create-research-post.mts <机构 id> "<研究岗名>"`：机构档案拼成 JD，走研究岗提示，Claude Opus 5.5 生成，空间挂到机构下。
3. `npx tsx scripts/lab-build-full-day.mts <空间> --model claude-opus-5-5 --hint "…"`：提示里写一天的节奏、人物沿用、哪几章会换专门台面。
4. 人物立绘查一遍：素材库按类型复用会跨行业串脸（这次导师、刘老师被复用成戴安全帽的工人），用 `drawCastAsset` 带性别年龄的外形描述重画。
5. 台面：写 spec（槽位照 `docs/lab-playbook.md`）→ 干跑示范 → `scripts/lab-upgrade-surface.mts <规格名> <空间> <时段>` 换进章节 → 理顺章节里步骤的先后和台词。
6. 3D：`scripts/beta3d/make-scene.mjs`，场景描述避开风险词。默认参数只长到 5 万高斯、满屏拉丝；截长轴（splat-cap.py）能去拉丝，但用户看着像「结了霜」（黑底 + 白色糊斑），弃用。
   最终做法：同一条视频 `--video` 重训，`--brush "--growth-grad-threshold 0.000015 --growth-select-fraction 0.3 --growth-stop-iter 24000"` 30000 步长到 25 万高斯；去掉离镜头太近的飘点和又大又艳的彩色团；亮的室内场景在 lab-3d-beta.ts 配 `bg` 浅灰底色。
7. 空间主页的「真活」入口：空间带 `org_id` 时，接口把这家机构的真活一起返回（同岗位排前面）。


## 3D 边缘糊：补拍左右两段（v4）

一条 Veo 视频只扫 40° 弧，画面边缘重建不出来。用 `veo.mjs --image=<原视频首帧 / 末帧>` 图生视频，接着往左 / 往右各扫一段（不给首帧的话 Veo 会生成另一间屋子）。
三段按「左段倒放 → 原视频 → 右段」排成一条轨迹，`sfm.py - <out> --images <合并目录>` 一起估机位，Brush 加大增长训练。
左右段的镜头站得更开，中间机位前面会长出大块飘点：按中间机位的视线深度去掉明显在场景前面的高斯，再去掉又大又细长的块。lab-art 桶单文件约 18 MB 上限，超了就按体积 × 不透明度截前 N 个。
