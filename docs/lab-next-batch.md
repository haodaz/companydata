# 百业第二批故事：往「模拟真能放大」的职业走

老王（2026-10-11 晚）的判断：月嫂、拉花、潜导这类偏体验型，情绪价值和人际互动在真实社会里才成立，虚拟再好也差一层——放几个可以，但放不大。真正能被模拟放大的是两类，再加一个按国民经济产业看的角度：

1. **机器中介型**：现实里本来就在屏幕和仪器上干活（芯片设计、CAD、精密仪器、数控、自动化）。模拟器和真实工作台几乎是同一个东西，工程教育认证那条线天然对接。
2. **高风险型**：真实世界不容易出现、出现就很麻烦（应急、消防、高压、高空、化工异常工况）。这些职业本身就靠模拟训练，没有替代品。
3. **一产、二产**：三产面向用户、最容易想到，但一二产在产业链上游、在 B 端，而且**工业场景能数采**——岗位在空间里的工况数据和行为画像，是能卖给大模型公司的东西（投资人要听的）。

两条原则不变：每个故事完整一天；视频 / 文案不出现具体数字。新片段做成**新视频**，不替换现有三条。

## 候选清单（按三条线）

### 一、机器中介型 —— 浅色整屏「桌面 + 多个应用图标」台面（Desk 这一套直接复用）

| 故事 | 一天里的关键操作 | 台面 | 3D 景深 |
|---|---|---|---|
